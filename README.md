# Личный финансовый трекер

Мобильное веб-приложение — личный финансовый трекер для одного пользователя.
Интерфейс на русском, валюта — рубли (₽). Данные хранятся в `localStorage`
браузера, без бэкенда и базы данных.

## Технологии

- Next.js (App Router) + TypeScript
- Tailwind CSS
- Хранение данных — `localStorage`
- Готово к деплою на Vercel «из коробки»

## Возможности

- **Сводка**: «на руках», доход/расход/разница за месяц, реальная позиция
  (на руках − остаток долга по кредиту), прогресс цели, ближайший платёж по кредиту.
- **Добавить операцию**: дата, тип, категория (зависит от типа), сумма, счёт, заметка.
- **Операции**: список за месяц, сгруппирован по дням с итогом расходов за день,
  фильтр по категории, редактирование и удаление.
- **Переключатель месяца** вверху экрана.
- **Настройки**: ручное редактирование балансов счетов, цели и параметров кредита.

Кредиты и займы считаются отдельно и **не входят** в «доход» и «расход».

## Запуск локально

```bash
npm install
npm run dev
```

Откройте http://localhost:3000

## Сборка

```bash
npm run build
```

## Деплой на Vercel

1. Запушьте репозиторий на GitHub.
2. Зайдите на [vercel.com](https://vercel.com) → **Add New… → Project**.
3. Подключите этот репозиторий → нажмите **Deploy** (настройки менять не нужно,
   Vercel сам определит Next.js).
4. После сборки откройте выданную ссылку на телефоне.

## Синхронизация с Google-таблицей (необязательно)

По умолчанию данные хранятся только в браузере. Чтобы пользоваться приложением
**с телефона и с компьютера** с одними и теми же данными (и иметь резервную
копию), можно подключить Google-таблицу как хранилище. Отдельный сервер не нужен —
всё работает через бесплатный Google Apps Script.

### Шаг 1. Создать таблицу и скрипт

1. Создайте новую Google-таблицу на [sheets.new](https://sheets.new).
2. В меню: **Расширения → Apps Script**.
3. Удалите содержимое файла `Code.gs` и вставьте код из
   [`apps-script/Code.gs`](apps-script/Code.gs) этого репозитория. Сохраните
   (значок дискеты).

### Шаг 2. Опубликовать как веб-приложение

1. Справа вверху: **Deploy → New deployment** (Деплой → Новый деплой).
2. Тип (шестерёнка) → **Web app** (Веб-приложение).
3. Настройки:
   - **Execute as / Запуск от имени** — `Me` (от своего имени).
   - **Who has access / У кого есть доступ** — `Anyone` (Все).
4. Нажмите **Deploy**, при первом разе подтвердите доступ к своему Google-аккаунту.
5. Скопируйте **Web app URL** — ссылку вида
   `https://script.google.com/macros/s/.../exec`.

### Шаг 3. Подключить в приложении

1. Откройте приложение → вкладка **Настройки → Синхронизация с Google-таблицей**.
2. Вставьте скопированную ссылку.
3. Оставьте галочку «Синхронизировать автоматически».
4. На другом устройстве откройте ту же ссылку приложения и вставьте тот же URL —
   данные подтянутся автоматически.

Кнопки **«Загрузить из таблицы»** и **«Сохранить в таблицу»** позволяют
синхронизировать вручную. При конфликте берётся более свежая версия (по времени
последнего изменения). В таблице появится лист **«Операции»** с читаемой
расшифровкой — удобно для просмотра и графиков (приложение редактируется через
интерфейс, а не правкой ячеек).

> Если меняете код `Code.gs` позже — в Apps Script делайте **Manage deployments →
> Edit → Version: New version**, иначе ссылка останется на старой версии.
