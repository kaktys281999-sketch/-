Порядок:

Ограничения:
- Не открывай сайт публично без пароля.
- Не коммить пароли/хэши/токены в репозиторий (секрет — только в
  `caddy-conf.d/auth.caddy`, он в .gitignore).
- Не редактируй на сервере файлы, отслеживаемые git.
- Если что-то идёт не так — сверься с разделом «Диагностика» в runbook и сообщи мне,
